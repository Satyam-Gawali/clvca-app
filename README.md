## 📱 About CLVCA

CLVCA is a revolutionary, privacy-first mobile application designed to enable faster, smarter, and completely secure voice translations across languages. By performing 100% of the speech-to-text, translation, and text-to-speech processing directly on your device, CLVCA operates without any server logs, cloud storage, or active internet connection.

## 🔄 Two Conversation Modes

CLVCA is engineered to adapt to any environment, supporting two distinct communication frameworks:

### 1. Single Device Mode (Face-to-Face)
Designed for two speakers sharing a single smartphone.
* 🌐 **Language Selection:** Tap the top card to configure custom speaking pairs.
* 🎛️ **Speech Tuning:** Modify regional accents, speed, and pitch parameters.
* 🖥️ **Rotated Fullscreen:** Rotates the translation card for simple readability for the person sitting across from you.
* 🔄 **Auto Mode:** Dynamic voice recognition switches microphones automatically.

### 2. P2P Mode (Wireless Device-to-Device)
Connects two separate phones using local Bluetooth and Wi-Fi networks.
* 📶 **Zero Cellular Data:** Operates without cell towers or central server relays.
* 🔲 **QR Code Pairing:** Connect hosts and guests instantly by scanning the secure QR room code.
* ⚡ **Model Installer:** Install local offline speech models once, translate infinitely.
* 🕒 **Offline History:** Session transcripts are cached locally on-device and can be purged instantly.

## 🔒 Privacy-First Commitment

We believe your voice belongs to you. CLVCA is constructed on a zero-trust cloud model:
* **No Transcripts Stored:** Conversations are never sent to external servers or sold to third parties.
* **Local Controls:** Purge all stored translations and downloaded language dictionaries from Settings at any time.
